# 宣传视频源码

`render.py` 生成 72 秒、1920×1080、24 fps 的 MP4，以及封面、字幕和联系表。字幕、动画、转场、背景音乐和编码均由代码完成。无下载音乐、素材库或真人配音。

```sh
python -m pip install -r promo/requirements.txt
python promo/render.py
```

Windows 默认使用微软雅黑。其他环境通过 `--font /path/to/CJK-font` 指定支持中文的字体。默认输出 `promo/rendered/`，也可以用 `--output` 指定目录。

`assets/` 是 2026-10-13 本机 DSH 原生窗口的真实裁剪截图，包括一次真实续接期间连续采集的画面。只保留演示会话；原始截图中的私人侧栏、账号与余额已裁去。视频有剪辑和镜头缩放，展示节奏不代表模型耗时。

流程图与完成回执卡明确标为示意或实际记录排版，不伪装成 Codex 截屏。片中不声称固定缓存命中率或节省比例。

素材由本项目演示生成。代码与音轨按项目 MIT 许可开放。截图中 DSH 产品界面及商标归各自权利人所有，用于说明插件操作。

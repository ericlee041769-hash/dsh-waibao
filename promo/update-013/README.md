# dsh-waibao 0.1.3 竖屏短片

44.70 秒，1080×1920，30fps，H.264/yuv420p + AAC。
内容通过字幕呈现，背景音乐由程序生成，无配音。

## 制作

依赖 Python 3.10+、Pillow、numpy、imageio-ffmpeg：

```sh
python -m pip install pillow numpy imageio-ffmpeg
python render.py
python render.py --preview
python render.py --times 9.4,9.8,10.4,11.8
```

默认输出到仓库的 `outputs/update-013/`。字体读取本机系统字体，不随源码分发；
没有微软雅黑的机器须用 `--font`、`--font-bold`、`--font-mono` 指定中文和等宽字体。

| 文件 | 职责 |
| --- | --- |
| `render.py` | 时间轴、镜头运动、字幕、封面和视频编码 |
| `shots.py` | 十二个镜头的文字、图形和状态动画 |
| `music.py` | 120 BPM 鼓、贝斯、和弦、琶音、立体声延迟与转场音，固定随机种子 13 |
| `timeline.json` | 总时长与字幕时间，供画面和音乐共同读取 |
| `captions.srt` | 可单独导入短视频剪辑软件的字幕 |

`music.py` 生成 48kHz 双声道音频，经 FFmpeg 归一化到目标 −16 LUFS、真峰值 −1.5 dBTP。
成片编码为 AAC 后需以实际测量为准。没有外部音乐或声音素材。
旧 TTS、SSML、旁白读取及人声混音路径已移除。

## 镜头

等待回信 → 小队就位 → 三任务并行 → 子任务主动汇报 → 父任务回复 → 单独停一个
→ 自由选择模型 → 历史更新回顾 → 0.1.3 更新卡 → 实测数据 → MIT 开源 → 收尾。

9.34–12.05 秒采用上方父任务、中间消息通道、下方子任务的布局。
单条消息沿通道向上投递，父任务收到后改变状态；子任务继续执行。
消息与文字不再覆盖进度条，不使用多张残影卡片或镜头推拉。
12.05–14.83 秒沿相反方向发送具体的接口核对要求，子任务收到后确认继续，
另外两个任务照常执行。画面不展示 append、job 等内部接口字段。

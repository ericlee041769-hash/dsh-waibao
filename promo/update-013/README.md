# dsh-waibao 0.1.3 竖屏短片源码

1080×1920 / 30fps / 44.69 秒 / H.264 yuv420p + AAC 有声短片，用于介绍
dsh-waibao 0.1.3 的并行派工与父子双向消息。

所有画面由 Pillow 逐帧绘制，音频由本机 TTS 旁白 + 代码合成的轻节拍组成。
没有第三方素材、没有版权音乐，也没有任何屏幕录制。

## 运行

    python render.py                  # 渲染全部帧并编码成片
    python render.py --preview        # 每个镜头取一帧 + 联系表，用于检查版式
    python render.py --times 3,26.9   # 只导出指定秒数的帧
    python render.py --frames-only    # 只导出帧，不编码
    python render.py --encode-only    # 用已有帧直接编码

依赖：Python 3.10+、Pillow、numpy，以及一个可执行的 FFmpeg。

`--ffmpeg` 不给时会先尝试 `imageio_ffmpeg.get_ffmpeg_exe()`，再退回 `PATH` 上的 `ffmpeg`。
装法示例：

    python -m pip install pillow numpy imageio-ffmpeg

## 路径

源码以本文件所在目录为基准，全部使用相对路径，可以直接搬到别的机器；
不依赖任何本机固定目录。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `--audio-dir` | `audio/` | 旁白、字幕与时长来源 |
| `--out` | `../../outputs/update-013/` | 成片、封面、联系表、字幕输出目录 |
| `--frames-dir` | `out/frames/` | 中间帧目录，编码后自动清理 |
| `--font` / `--font-bold` / `--font-mono` | 系统微软雅黑 / 雅黑粗体 / Consolas 粗体 | 中文与等宽字体 |
| `--ffmpeg` | 自动探测 | FFmpeg 可执行文件 |

字体不随仓库分发，读取的是本机系统字体；换到没有雅黑的机器时，
用 `--font` 指向任意中文 TTF/OTF，或用环境变量 `WINDIR` 指定字体目录所在系统盘。

## 文件

    render.py    时间轴、镜头边界、镜头运动、常驻 HUD、字幕、节拍、编码入口
    shots.py     绘制原语（文字、色块、条形、气泡、印章）与十二个镜头
    audio/       旁白 voiceover.wav、narration.json（逐句时间）、captions.srt
    out/         本机构建产物，已忽略

镜头边界直接来自 `narration.json` 的十二句时间点，末句之后再补 1.5 秒收尾卡。
改文案或语速后重跑即可，不需要手改时间码。

封面单独绘制“我给 Codex 接了一支能回话的 AI 小队”，不截取带旁白字幕的视频帧。

首次从 Git 源码制作时，先按 [audio/README.md](audio/README.md) 生成旁白。发布页的视频源码 ZIP 已附同一份 WAV，可直接渲染；成片、封面和字幕也可单独下载。

## 画面里标注的含义

- **工作流示意**：镜头 1–9 的状态、进度、消息流动都是动画示意，用来解释机制，
  不是软件录屏，也不是真实耗时。
- **实测记录重排**：镜头 10 的数字来自 2026-10-24 真实 DSH Desktop 0.2.1-rc.2
  会话（aggregate / deepseek-v4-1-flash / high）的记录，画面是按记录重新排版的，
  不是截图。
- 镜头 11–12 的 MIT 徽标同理，属于排版，不是截图。

剪辑节奏与模型实际耗时无关；片中不给出加速比、节省比例或逐个模型的实测结论。

## 声音

- 旁白：`audio/voiceover.wav`，本机中文 TTS 生成，48kHz 双声道 PCM，
  逐句时间在 `audio/narration.json`。
- 节拍：`render.py` 里的 `build_bed()` 用 numpy 合成软底鼓、踩镲、冲击音与
  低频垫音，按旁白时间点对齐，混音时自动给人声让出余量，峰值不超过 0 dBFS。
  没有引入任何外部音乐或音效文件。

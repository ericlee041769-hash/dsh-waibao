# 开源 dsh-waibao：让 Codex 把任务交给 DSH，过程看得见，后续接着做

我做了一个 DSH 插件：**dsh-waibao（DSH 外包）**，现已按 MIT 协议开源。

用一句话介绍：**Codex 拆解任务、检查结果，DSH 在桌面会话中执行；需要修改就沿用同一个会话，完成后通知 Codex 继续验收。**

做它的原因很简单：委派任务以后，我想知道它进行到哪一步，也想让下一轮修改接着之前的上下文继续。

它解决了三个具体问题：

- **不用猜进度。** 委派任务直接出现在 DSH 原生工作区，正文、工具过程和实际用量都能查看。
- **少重复交代。** 后续任务复用同一个会话，前一轮讨论过的背景和要求可以接着用。
- **不用守着等。** 任务结束后，完成通知回到发起任务的 Codex 聊天，继续检查产物、安排修改。

例如，让 DSH 完成功能实现，再由 Codex 检查差异和测试；发现问题后，把修改要求发回原会话。这套流程适合需要反复修改的开发任务，也适合耗时较长的检查和测试。

附上 72 秒真实桌面演示：第一轮记住项目代号和交付约定，第二轮在同一会话里正确复述，两轮完成通知均已收到。视频的字幕、镜头编排、转场、音乐和编码全部由 AI 编写的脚本生成，制作源码也在仓库里。

首版支持 Windows，已实测 DSH Desktop 0.2.0-rc.2、Node.js 24 和 Codex Desktop。运行时零第三方依赖。缓存命中率与费用请结合所用模型服务商的实际用量判断。

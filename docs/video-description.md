# 视频发布素材

## 标题

开源 dsh-waibao：Codex 派活，DSH 干活，过程看得见

## 简介

做了一个 DSH 插件，让 Codex 分配任务，DSH 在桌面会话中执行，完成后通知 Codex 继续验收。

三个实际好处：不用猜进度、少重复交代、不用守着等。适合多轮开发、反复修改，以及耗时较长的检查和测试。

这段 72 秒视频展示真实桌面会话：第一轮记住项目代号和交付约定，第二轮在原会话中继续。视频的字幕、镜头编排、转场、音乐和编码全部由 AI 编写的代码生成，制作源码一并开源。

GitHub：https://github.com/ericlee041769-hash/dsh-waibao
Gitee：https://gitee.com/sensenlee/dsh-waibao
安装包：https://github.com/ericlee041769-hash/dsh-waibao/releases/tag/v0.1.0

MIT 协议。首版支持 Windows，实测环境为 DSH Desktop 0.2.0-rc.2、Node.js 24、Codex Desktop。缓存与费用以模型服务商实际用量为准。

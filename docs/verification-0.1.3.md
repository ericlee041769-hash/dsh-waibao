# 0.1.3 验收

2026-10-24，Windows，DeepSeek Harness Desktop 0.2.1-rc.2、Node.js 24.14.0、Codex Desktop。

## 本地集成测试

28 项测试全部通过。测试使用假 Host / App Tools 与真实 CLI、后台协调进程和本地管道，覆盖三任务并发、同任务重入拒绝、父线程隔离、部分启动失败、执行中消息、父回复和停止隔离、消息投递失败、任意模型标识与桌面切换模型后的续接，以及原有审批、问题和资源清理。

## 真实桌面与模型

通过桌面 CLI 安装 0.1.3，重启后 `describe` 返回 `version: "0.1.3"` 与 `capabilities.parentMessages: true`。

沿用当时配置的 `aggregate / deepseek-v4-1-flash / high`，没有为测试固定插件模型名单。一次并行派发三个独立任务：

- 三个任务同时进入运行状态，原生日志均记录模型步骤开始。
- 两个正常任务各发送三条主动消息，合计六条；全部在任务完成前通知发起的 Codex 聊天。
- 父任务分别给两个运行中的子代理追加回复；两条回复都记录为已消费，子代理分别回信确认标记。
- 独立停止第三个任务，返回 `cancelled`；另外两个继续完成。
- 三个任务的完成回调均成功返回；工具错误和消息投递错误均为零。

首次观察窗口为三分钟，届时真实模型步骤尚未全部结束；继续跟踪原有任务，没有重新派工或重复模型请求，最终全部完成验收。该路由本轮模型步骤存在明显等待，因此本记录不构成速度基准，也不代表所有提供商和模型均已逐一测试。

公开记录仅保留验收结论，不包含本机连接令牌、私人路径或原始会话日志。

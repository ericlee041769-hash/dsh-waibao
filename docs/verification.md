# 0.1.0 验收

2026-10-13，Windows，本机 DSH Desktop 0.2.0-rc.2，Node.js 24.14.0。

- 标准 `dsh.bundle` 包经桌面自带插件管理器安装；Host 返回已安装 package 的模块路径。
- 集成测试：本地管道鉴权；同一 session 连续请求；未知会话、工作区不匹配、忙碌、重复 requestId、模型变化拒绝；历史接入；CLI 绑定落盘；卸载资源清理。
- 两轮真实模型调用：第一轮保存“青竹-7316”和“每次说明验证结果”；第二轮只询问上轮内容，正确复述。两轮均成功退出，实际 completion 回到发起 Codex 聊天。
- 模型保持 `buddy / deepseek-v4.1-flash / high`。会话和两轮正文在桌面实际打开。
- 演示视频只使用专用演示会话的裁剪截图，排除私人项目侧栏、账号、余额和连接令牌。

新工作区默认折叠。展开箭头位于工作区行的左侧；点击名称本身不会展开。开发中误判成刷新问题的重复通知代码已经撤掉。

必要模块：Host 负责原生会话与本地 IPC，CLI 负责绑定，job 负责完成记录和回调，paths 保持双方路径一致，read-run 提供有界用量摘要，技能指导 Codex 调用。

本包移除了安装盘符依赖、独立进程接管模式、额外 PowerShell 等待器和测试中冗余的 RPC 函数。保留任务本身的错误、未知投递结果与资源释放处理。没有打包旧开发接入、私人日志或运行状态。

另一插件 dsh-chat-assistant 的 Hook 本地修复不属于本发布包；本插件不修改它或 DSH 的 ASAR。
